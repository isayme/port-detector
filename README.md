# Download

Install by script:

```
curl -fsSL https://raw.githubusercontent.com/isayme/port-detector/refs/heads/master/install.sh | bash
```

or 

```
wget -qO- https://raw.githubusercontent.com/isayme/port-detector/refs/heads/master/install.sh | bash
```

Get binary for your os from [Relases](https://github.com/isayme/port-detector/releases).
